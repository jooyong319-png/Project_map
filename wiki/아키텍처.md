# 아키텍처

[[콕콕콕]]의 기술 구조. **2026-10-13 정리 이후** 기준 (구글·DB·로그인·즐겨찾기·지구본 제거). 기준 문서는 [[브리프]].

## 한 줄

공공데이터로 동네 데이터를 **미리 빌드해 정적 JSON**으로 두고, 사용자가 동네·역을 고르면 서버 함수가 그 안에서 후보를 골라 Gemini에게 **고르기·순서·이유만** 맡긴다. DB 없음.

## 스택

- 화면: React + Vite SPA, 지도 react-leaflet + MapLibre 벡터 타일(OpenFreeMap)
- 서버: Vercel 함수 `api/*.js` (로컬은 `vite.config.js`의 미들웨어가 같은 핸들러 실행)
- 앱: Capacitor(Android) — 아직 라이브 URL 로드 방식 ([[다음-목표-앱화]], 4단계)

## 데이터 흐름

```
[오프라인 빌드 — 로컬에서 사람이 실행]
data_raw/*.csv (인허가·백년가게·착한가격·주차장) + TourAPI
   └─ scripts/buildArea.mjs <slug>   → src/data/places/<slug>.json (장소·영업시간·태그)
   └─ scripts/buildArea.mjs <slug> --refresh-hours  → 영업시간만 갱신(월 1회, 오래된 것부터 하루 300건)
        └─ scripts/enrichArea.mjs    → + 인기 점수(pop, 연관 관광지) · 데이트 적합도(fit/night, Gemini) · 공영 주차장
   └─ scripts/aiPick.mjs <slug>      → <slug>.picks.json ('AI 픽', 사람 검수 대상)

[요청 시 — 서버 함수]
/api/course  ← bbox · theme · from(역) · car · fixed(정해 둔 일정) · st(만나는 시각) · first(첫 순서) · wish(직접 쓴 요청) · ex(다른 코스)
   lib/areas.js: 동네 데이터 + picks 병합
   → 중심 관광지 선정(fit/night·pop) → 반경 1km 후보 → Gemini(JSON 스키마) → 실재 id 로 복원
   → 구간 이동시간(카카오모빌리티·도보·ODsay) · 주차장(공영=데이터, 민영=카카오 실시간)
```

## 서버 함수 (5개)

| 경로 | 하는 일 | 외부 |
|---|---|---|
| `/api/course` | AI 하루 코스 | Gemini, 카카오(길찾기·주차장), ODsay(선택) |
| `/api/kakao` | 장소 검색(목록) | 카카오 로컬 — 실시간만 |
| `/api/suggest` | 검색 자동완성 | 카카오 로컬 |
| `/api/plan` | 한 문장 → 코스 조건(동네·시각·첫 순서·정해 둔 곳·분위기) | Gemini flash-lite (사용자가 쓴 문장만) |
| `/api/geocode` | 동·구·역 → 좌표 | 카카오 주소·키워드 |
| `/api/place?blog=1` | 상세 화면 블로그 후기 수 | 네이버 검색 — 실시간만, `private` 캐시 |

## 폴더

| 위치 | 내용 |
|---|---|
| `api/` | 서버 함수 5개 |
| `lib/areas.js` | 동네 데이터 로더(`placesIn`, `parkingNear`) — 새 동네는 `FILES`에 한 줄 |
| `lib/naver.js` | 블로그 수 실시간 조회 + 이름 정규화 |
| `scripts/` | `buildArea` · `enrichArea` · `aiPick` (동네 추가 시 `AREAS`·`RLTE`·`HINTS`에 한 줄씩) · `checkCourses` (`npm run check` — 코스 규칙 점검, 고친 뒤 돌리기) |
| `src/data/places/` | 동네 데이터(커밋됨) |
| `data_raw/` | 원본 CSV·TourAPI 캐시 (gitignore) |
| `src/pages/Home.jsx` | 검색·목록·코스·지도 한 화면 |

## 약관 경계 (코드로 지키는 것)

- 카카오: 결과 저장 금지(장소ID·place_url만) → 검색·주차장 민영은 실시간만
- 네이버 검색: 저장·AI 입력·광고 화면 금지 → 상세 화면 실시간 표시만, 코스 엔진엔 안 들어감
- 공공데이터: 전부 "이용허락범위 제한 없음" → 저장·AI 입력 가능
- 상세 화면(네이버 후기 수 표시)엔 **광고 금지**
